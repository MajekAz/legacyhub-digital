==================================================
LEAD CRM ARCHITECTURE — GOOGLE WORKSPACE
==================================================

Do NOT use Supabase as the lead/customer CRM.

LegacyHub Digital Heritage will use a custom Google Workspace CRM based on:

- Google Sheets
- Google Apps Script
- optional Google Forms for later internal/client workflows

The public website must submit leads through a secure Next.js server Route Handler.

Required architecture:

Visitor
→ Website form
→ POST /api/leads
→ server-side validation
→ server-to-server request
→ Google Apps Script Web App
→ Google Sheets CRM

Do NOT expose Google Apps Script secrets in browser code.

Do NOT allow public browser code to write directly to Google Sheets.

Do NOT use client-side fetch directly to the Apps Script Web App.

Create server-side environment variables:

GOOGLE_CRM_WEBAPP_URL
GOOGLE_CRM_SHARED_SECRET

Optional:

LEGACYHUB_LEADS_EMAIL
NEXT_PUBLIC_BUSINESS_WHATSAPP
NEXT_PUBLIC_GA_ID
NEXT_PUBLIC_META_PIXEL_ID

All secrets must remain server-side.

    "preferredContactMethod": "...",
    "message": "...",
    "sourcePage": "...",
    "landingPage": "...",
    "referrer": "...",
    "utmSource": "...",
    "utmMedium": "...",
    "utmCampaign": "...",
    "utmContent": "...",
    "utmTerm": "..."
  }
}

Apps Script response:

{
  "ok": true,
  "leadId": "LHD-0001"
}

Failure response:

{
  "ok": false,
  "error": "internal_error"
}

The website must never expose raw Apps Script errors, Sheet IDs, implementation details or secrets to visitors.
